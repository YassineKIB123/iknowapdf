# Code of conduct

Be respectful in issues, pull requests, and other project spaces. Welcome contributors with different backgrounds and experience levels, give feedback on the work, and respect people’s privacy.

Harassment, threats, discriminatory language, personal attacks, and sharing someone’s private information without permission are unacceptable.

Report concerns privately to [support@iknowapdf.lol](mailto:support@iknowapdf.lol). Include links or context if you can. Maintainers may remove content or restrict participation to keep project spaces safe.
